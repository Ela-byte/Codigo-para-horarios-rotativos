# Horarios
                                                                            Pruebas de los horario rotativos 
                                    Que buscamos es hacer una aplicacion para la semana es decir la informacion que nos compartieron fue la siguiente:
Para 9 personas de los cuales debemos acomodar de la siguiente manera  
                    Tenemos lo siguiente horarios:
                    
        >> En la Mañana <<
          {
          7 am - 4 pm
          9 am - 6 pm
          11 am - 8 am
          }
        >> En la Noche <<
          {
          3pm - 11 pm
          }
          
  -Estos horario son para de lunes a viernes pero hay otra variante-
                  Los dias sabados y domingos son lo siguientes:
      
       >> En la Mañana <<
         {
         7 am - 4 pm
         }
       >> En la Noche <<
         {
         3pm - 11 pm
         }
Ademas hay que considerar que necesitamos 3 personas que esten en la mañana, 2 que esten en la noche; Mas aparte que los descansos deben ser 2 por personas.
